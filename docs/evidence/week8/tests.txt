    2. 멀티시그 동작 (제안 → 승인 → 실행)

      √ 두 번째 관리자가 승인하면 실행된다 (66ms)

      √ 제안 시 제안자의 승인 1표가 자동으로 들어간다
    3. 비상 정지 (Emergency Stop)
      √ 강제종료는 2명 승인 후에만 실행되고, 이후 투표가 차단된다 (114ms)

    4. 투표 무결성
      √ 미등록 유권자는 투표할 수 없다 (41ms)

      √ 존재하지 않는 후보에는 투표할 수 없다 (52ms)
      √ 선거 시간이 지나면 투표가 거부되고, 결과 확정 후 당선자를 조회할 수 있다 (77ms)

      √ V-B 방어. 선거 시작 후 관리자 1명이 후보를 추가하려 하면 거부된다 (84ms)

      √ 선거가 끝난 뒤에도 등록은 차단된다 (선거 1회용 정책) (50ms)
